# DigiMedia Landing Page

A responsive, multi-page digital agency website with a client profile and project-status dashboard prototype.

## Client dashboard

Choose **Sign Up**, enter a name and email, and the site opens a profile dashboard. From there, a visitor can add projects, update each status (Inquiry, Planning, In Progress, Review, or Completed), and remove projects. The profile and project list are saved in the current browser using `localStorage`.

## Important limitation

This is a static GitHub Pages site. Signup is a local demo profile, not a secure account: it has no password, server-side identity, shared database, or agency-managed project updates. Data is available only in the same browser on the same device and can be cleared with browser storage. Real customer accounts and staff-managed project status require a backend and authentication.
